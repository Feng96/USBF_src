# Scientific scope and author follow-up

The tested local project generates a real small example from frozen weights and replays all fixed geometry metrics. It is not a national inventory reconstruction or a new scientific experiment. The default configuration includes the evaluated circular search and exact-ID OSM confirmation. Later nationwide configurations that disable new circle search are a different branch and have not replaced this manuscript method.

The primary sample contains no final accepted circular/elliptical replacement, hole change, instance deletion or split. Positive synthetic circle/hollow tests verify code branches but cannot provide accuracy estimates for absent modification types. The separate reference-selected curved sample retains its own nine/seven pair counts and four unmatched targets.

Ground registration supplies image-relative correspondence, not surveyed absolute accuracy. Neither non-OSM provenance nor government origin automatically proves independent reference truth. NAIP/SpaceNet acquisition dates, roof-versus-base labeling conventions and unresolved historical source/training overlap remain relevant.

National figures such as 150,700,231 source records and 181 circular replacements are not established by this example, the SpaceNet sample, script constants or a CSV copied into the package. They need the separate complete national production/release ledger. This software does not manufacture those counts. No manuscript original has been edited.

For author wording, distinguish three scopes: small real-image generation verified; complete fixed-geometry evaluation verified; full-sample image generation and complete model retraining not executed. Curved-candidate thresholds apply to the relevant fitted-candidate branch; previously qualified primitive preservation remains explicit in the historical source. Do not silently rewrite a scientific branch to make prose appear simpler.

The current shared main/S1/S2 documents were read before packaging; they remain revision-bearing Word files, and a readable preview is not proof that authors accepted tracked changes. `manuscript_mapping.csv` records implementation and evidence links. Public repository/license confirmation and final remote-clone acceptance remain release gates, separately reported in `release_validation.json`.

Its pre-confirmation regional curve output cannot be described as a successful exact-OSM-confirmed replacement under the current rule.
